# F - NIL
A slightly over-ambitious attempt at building an F1 simulator in Unity. What started as “make car go fast” quickly turned into learning about Ackermann steering, power curves, gear shifting, and a lot more vehicle behavior than I originally planned. It’s far from a perfect simulation, but it was a fun project that taught me a lot about both programming and how cars actually work.
